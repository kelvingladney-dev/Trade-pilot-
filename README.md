# TradePilot Mobile

This is a phone-friendly Streamlit version of the stock trading tool.

## Put it online so your phone can open it
1. Create a free GitHub account.
2. Create a new repository.
3. Upload `app.py` and `requirements.txt`.
4. Open Streamlit Community Cloud and deploy the repository.
5. Open the generated web-app link on your Android phone and save it to your home screen.

The app provides price charts, SMA/RSI/MACD, rule-based signals, position sizing, and a basic historical backtest.

It does NOT place real trades.
